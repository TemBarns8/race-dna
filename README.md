# Race DNA

Race DNA is an explainable Formula 1 driver analytics platform.

The project transforms race results, lap data, weather, tyre stints, and pit
stops into transparent and versioned driver metrics.

## Project goals

- Explore a driver's complete racing history
- Compare seasons
- Visualize wins, podiums, and pole positions
- Calculate explainable Race DNA indices
- Analyze individual races
- Experiment with alternative pit-stop strategies

## Current status

The project is in the early MVP development stage.
